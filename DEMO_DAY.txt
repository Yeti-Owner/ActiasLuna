ACTIAS DEMO DAY: boards -> laptop (Wi-Fi) -> Vultr (Ethernet) -> Chert FaceTime
===============================================================================

Network: the laptop's Wi-Fi joins the boards' network WATCHING-YOU (no internet). Its Ethernet cable gives
internet for Vultr, Chert, LiveKit and Gemini. Windows prefers wired Ethernet automatically; CHECK.cmd confirms it.

All three files below are in the repo folder. Double-click them.


1. CONNECT
   - Plug in the Ethernet cable.
   - Power the three boards (A, B, C).
   - Wi-Fi: join WATCHING-YOU. Windows will say "No internet". That's expected; Ethernet carries the internet.
   - Turn OFF any VPN (TunnelBear etc.); it would pull Vultr traffic off the Ethernet.

2. START THE SERVER        START_BACKEND.cmd     (leave this window open the whole time)
   It prints   cloud: this is run-YYYYMMDD-HHMMSS   and   cloud: uploading to https://149-28-97-171.sslip.io
   Each start is a new run. Chert only ever hears about the newest run, so earlier tests never leak in.
   The dashboard (room scan, boards, calibration) opens by itself: http://127.0.0.1:8080/
   Phone page (controls, I'm here, walks): the address the dashboard shows under Setup -> Calibrate.
   Second laptop (website + live 3D room from Vultr): copy config\cloud.json to it, double-click FRONTEND.cmd.

3. RUN IT A BIT
   Join a phone to WATCHING-YOU (or just walk in, for body tracking). Then do this walk, so there's a story to ask about:
     walk in -> stand next to board A for ~10 s -> walk to board B, stand ~10 s -> walk out of the room
   ("Stood by" = within about 1 m (3 ft) of a board for 3+ seconds.)

4. CHECK                   CHECK.cmd             (free: makes no Chert call)
   Every line should say OK and the end should say READY. The key lines:
     "Internet goes out over another adapter (10.x...), not the demo Wi-Fi"   <- Ethernet is doing the upload
     "Boards online: A, B, C"
     "Moth server uploading as run-...: ok, 0 waiting"
     "Vultr has this run's data, newest N s old"                               <- laptop -> Vultr is live
     "Vultr round trip: wrote a test visit, read back the right story"         <- Vultr stores and narrates
     "Chert agent reads Vultr with its own token. It would say right now:"     <- what Chert will say on the call
   The "recent:" line should describe your walk from step 3, e.g.
     "Someone entered 2 minutes ago, stood by point A for 10 seconds, then wandered to point B and stood there for
      9 seconds, then left 1 minute ago."
   If that line says it, the call will too.

5. CALL                    CALL_ACTIAS.cmd       (this is the only step that uses Chert)
   It runs the check again, opens the agent in a second window, and puts it on your Chert line.
   When it says it's listening, FaceTime the Chert line from the verified iPhone and ask:
     1. "Is anyone in the room right now?"
     2. "What happened in the last five minutes?"     -> should match the "recent:" line from CHECK
     3. "Where are they standing?"
     4. "Who was it?"                                  -> should say it can't know who, only where
   Press Ctrl+C in the CALL window when you hang up. That stops the line and the agent, so no Chert time is used idle.


IF SOMETHING FAILS
   "Internet traffic is going out over the demo Wi-Fi"
        Ethernet unplugged or not working, or Windows prefers Wi-Fi. Admin PowerShell, once:
          Set-NetIPInterface -InterfaceAlias 'Wi-Fi' -InterfaceMetric 100
   "Laptop is not on the demo Wi-Fi"           Wi-Fi isn't on WATCHING-YOU, or the boards are off.
   "Boards online: none"                       Boards off or still booting; wait 10 s. Firewall must allow python.exe.
   "Moth server not running"                   START_BACKEND.cmd isn't open.
   "Moth server uploading ...: cloud unreachable"   Same as the first item: no internet on Ethernet.
   "Laptop clock is N s off"                   Chert refuses calls if the clock is fast; see chert\README.md.
   Agent window closes straight away            Run:  powershell -ExecutionPolicy Bypass -File chert\run.ps1 agent
   Changed a key                                Edit chert\moth-room\.env.local, then run
                                                powershell -ExecutionPolicy Bypass -File chert\setup.ps1
